# Oracle Press Release
Oracle Press Release: Vertex Data Deal Terminated

## Oracle Corporation
Oracle Corporation confirmed today that it has formally terminated the previously proposed agreement to acquire Vertex Data, a real-time data streaming and analytics pipeline provider. Oracle cited unresolved regulatory concerns as its reason for walking away from the transaction.

## Vertex Data
Vertex Data, originally founded by technologist Alex Vance, was not ultimately acquired by Oracle. Following the collapse of talks, Vertex Data was later acquired by an undisclosed enterprise buyer; the acquiring company's identity was never made public.

## Oracle transaction
With the Oracle deal officially dead, neither company disclosed further details about the abandoned transaction. Oracle's Data Management Group ultimately expanded its streaming-analytics capabilities through other means.
